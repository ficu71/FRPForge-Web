# WifiCCrackConnectorApp

This sample project contains minimal Android and Windows applications that
show basic WiFi status information. Use Android Studio to open the
`Android` folder or a C# compiler to build `Windows/WifiConnector.cs`.

```
# Android
Open the project in Android Studio and run on a device or emulator.

# Windows
mcs WifiConnector.cs && mono WifiConnector.exe
```
